# band-sheets

バンドの楽譜を、パートごとの画面で書くアプリです（α版）。PC で編集し、タブレットで見ながら演奏することを想定しています。曲はテキストファイル（ChordPro と alphaTex の組み合わせ）です。このページは、アプリを試してみたい人（バンドの仲間など）と、開発に加わる人に向けた案内です。

## 試す

https://mrkkkkk.github.io/band-sheets/

- 「サンプル曲で試す」から、ログインなしですぐ使えます。
- ログインしないと、曲はこの端末のブラウザの中にだけ残ります（別の端末では開けません。ブラウザのデータを消すと消えます）。

## Google Drive に保存する

- 自分の Google Drive に保存するには、Google アカウントでのログインが必要です。PC とタブレットで同じ曲を使えます。
- マイドライブの `band-sheets` フォルダに、曲ごとの `.bandsheet`（テキスト）ファイルとして保存されます。アプリが見られるのは、アプリ自身が作ったファイルだけです（`drive.file`）。ほかのファイルは見えません。
- 公開中のアプリは Google の「テスト中」の状態です。**オーナーが登録したアカウントしかログインできません。** 使いたいときは、オーナーに Google アカウントのメールアドレスを伝えて、登録してもらってください。

## できること

- **コード譜と歌詞**: かんたん入力 / テキスト入力。`|[C]----[F]----|` のようなダッシュ記法で、コードだけの行も書けます。
- **メロディ**: 五線に音を入力し、歌詞やコードを付けられます。メロディの画面で再生できます。
- **ドラム**: 9 点のドラム譜。連符とシャッフルに対応しています。
- **タブレットで見る画面**: ページ送り / スクロール / 自動スクロール、移調。フットペダルはキー操作（PageDown・Space など）で使えます。
- **録音から新しい曲**: 音声ファイルから、テンポ・調・コードの下書きを作ります（PC のみ）。
- **鼻歌から下書き**: クリックを聞きながら歌った録音から、メロディの下書きを作ります（PC のみ）。
- 音声はサーバーに送らず、解析はブラウザの中で行います。結果は正確な書き起こしではなく、直す前提の下書きです。
- 編集中の内容は端末に自動で保存されます。Drive の版と食い違ったときは、保存の前に確認が出ます。

## 推奨環境

- 編集と音声の解析: PC の Chromium 系ブラウザ（Chrome など）。
- 見る画面: タブレット（Chromebook の Chrome で確認しています。iPad の Safari は未確認です）。

## 開発

```sh
npm install
cp .env.example .env.local   # Google Drive を使う場合は VITE_GOOGLE_CLIENT_ID を設定（docs/m7-google-setup.md）
npm run dev
```

- Storybook のテストと E2E（Playwright）は、Dev Container の中で実行します。
- 要件と設計のメモは [docs/](docs/) にあります（[docs/requirements.md](docs/requirements.md) から読むのがおすすめです）。開発の約束事は [CLAUDE.md](CLAUDE.md) にあります。
