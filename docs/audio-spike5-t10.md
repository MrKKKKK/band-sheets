読む人: ユーザー（次の関門で「未知のキット」の目標を決める人）と、T11（S-9）以降の担当。
目的: G1 の決定を残し、T10 で試した切り替えの結果（調整用・プリセットを外した評価・開発用の確認）と、採った設定を 1 か所にまとめる。

## G1 の決定（ユーザー、2026-10-25）

1. 優先は**未知のキットへの強さ**（ユーザーの録音は aD5 = 未知のキット）。方法は録音ごとの合わせ込み（その録音の確かな打点からテンプレートを作り直す）と、キットに依らない特徴（減衰の速さ、録音の中での帯域の位置）。調整はキット A だけ、キット B は確かめるだけ。
2. 目標を 2 つに分ける。**既知のキット**（調整に使ったキット）: §5 の仮の値（各楽器 F D0 ≥ .98・D1 ≥ .95・D2 ≥ .90、格子・シャッフルは §5）で**確定**。**未知のキット**: T10 の結果を見て次の関門で決める（今は数字を残すだけ）。
3. 直す手数/キーボード: D2 で ≤ 0.2 のまま。
4. Worker の大きさ 25.5 KB 対 25 KB: 記録だけ。T13 で決める（足したものの大きさは書く）。

## 評価の方法

- 実行: コミット `424babf`、設定 `drum-v0` ハッシュ `a3e68494763b`。ホールドアウトは走らせていない。
- **分類だけの表**（`ts/drum/classify_eval.ts --split tuning [--templates-program N] --sweep`）: 調整用 114 本の F50（全体、BD/SD/HH）。量子化の前の時刻で採点するので、通しの表とは値が少し違う（特に D2 の HH）。
- **プリセットを外した評価（LOPO）**: 調整用の録音（D0〜D2 = キット A の Standard、D3 = Power）を、別のプリセット（16 Power・24 Electronic・25 TR-808）のワンショットで作ったテンプレートで分類する。テンプレートと音が違う「未知のキット」を調整用の中で作る。注意: sf2 のアコースティックのプリセットは HH・HO・RD・CR が同じサンプルなので、キット B の「HH が RD に吸われる」はほぼ再現しない（808 だけ HH・RD が違う）。BD・SD の違いは再現する。
- **通しの表**（`cli.ts --all`）: §5 の目標を見る正式の値。
