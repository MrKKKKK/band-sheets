## 合成と本物の違い（気づいたこと）

1. **ベース入りは本物では名前を上げ、合成では下げる**: 録音 ALL .546 → .577（T8 形）に対し、合成の B は .670 → .640、LR は .835 → .750。本物には LR の左手（5-1-5'-1）の形が無く、誤った `/X` がほぼ 0 だから。後戻りの基準を何にするかで判定が変わる（G1 の決定 4）。
2. **本物の方が直す手数が多い**: 録音 ALL 28〜30 / 100 拍、合成 18〜19。g〜j は 40（落）・59（全）で、点の 60 % が今の語彙に無い種類のため。
3. **新しい種類は本物でも合成でもまだ出ない**（`sus2` を除く）。T10〜T12 の調整の余地は録音でも同じ。
4. **V2 の後戻りが本物にも出た**: g〜j の名前 .439 → .422（i .519 → .444）。合成の LR .835 → .797 と同じ向き（`sus2` が 3 和音を取る）。
5. **`/X` の点のルート**は本物 .277 と合成 B1 .235 でほぼ同じ低さで、+4 のずれが一番多いのも同じ。+4 を全部直すと本物で約 +.26。
6. **分数の適合率は本物の方が高い**（.89〜.95。合成 .80〜.87）。再現率は .20〜.23 で合成と同じくらい低い。
7. ベースにだけある音（16 区間）は、どの行でも当たらない（v1a・v2 は `/X` を出さず、ベース入りもその区間で `/X` を付けていない）。

5. **直す手数の基準**: 案 A（おすすめ）基準（T8 形。録音 28.2、合成 19.0）より減る。案 B G2 既定（27.2 / 18.3）より減る（厳しい）。
