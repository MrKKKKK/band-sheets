# テキスト形式の比較（M1 スパイク）

2026-10-03 実施。スパイクのコードは `spikes/format/`（アプリ本体とは別の依存関係）、スクリーンショットは `docs/format-spike/` にある。

## 方法

同じサンプル曲（きらきら星 4小節: コード + 歌詞 + メロディ、ドラムの8ビート3小節 + 16分のフィル）を3つの形式で書き、devcontainer 内の Chromium で描画した。

| 案  | 中身                                                                                                          | 描画                              |
| --- | ------------------------------------------------------------------------------------------------------------- | --------------------------------- |
| A   | alphaTex だけで全パートを書く                                                                                 | alphaTab 1.8.4                    |
| B   | ABC 記法だけで全パートを書く                                                                                  | abcjs 6.7.1                       |
| C   | ChordPro をコンテナにし、コード譜は ChordPro、楽器パートは `{start_of_part: 名前}` ブロックに alphaTex で書く | コード譜は自前、パートは alphaTab |

## 結果

| 評価軸                                           | A. alphaTex                                       | B. ABC                                                               | C. ChordPro + alphaTex                          |
| ------------------------------------------------ | ------------------------------------------------- | -------------------------------------------------------------------- | ----------------------------------------------- |
| メロディなしのコード譜（歌詞 + コードだけ）      | ✕ 音符がないとコードを置けない                    | ✕ 同左（`"C"x4` のような見えない休符が必要）                         | ◎ ChordPro そのもの                             |
| テキストとしての読みやすさ（Drive で開いたとき） | ○ `(HH BD) HH` のようにドラムを名前で書ける       | △ ドラムは音高の文字で書く（`[gF]g`、意味は `%%percmap` で別途定義） | ◎ コード譜は一目でわかる。パート部分は A と同じ |
| ドラム譜の見た目                                 | ○ 打楽器記号と×符頭。`\clef neutral` の指定が必要 | ◎ 初期設定のままきれい                                               | ○ A と同じ                                      |
| 将来の Tab譜                                     | ◎ ネイティブ対応（`3.5` = 5弦3フレット）          | △ 音高から自動生成するだけで、弦とフレットは指定できない             | ◎ A と同じ                                      |
| 入力途中の不完全なテキスト                       | ○ 例外は出ず、`error` イベントで通知される        | ○ 例外は出ず、警告の配列で返る                                       | ○ A と同じ                                      |
| ライブラリのサイズ（gzip）                       | 約 279 KB（再生機能込み）                         | 約 149 KB                                                            | 約 279 KB                                       |
| 再生（練習用に将来使う）                         | ◎ 内蔵                                            | ○ 内蔵（MIDI）                                                       | ◎ A と同じ                                      |

補足:

- alphaTab は初期設定のままだと、ドラム譜にト音記号が出て、最初の音符に強弱記号「f」が自動で付く。`\clef neutral` と `notation.elements` の設定で直ることを確認した（`docs/format-spike/shot-a.png`）。
- 案 C の画像でコードの位置がずれているのは、スパイク用の簡易レンダラーが日本語を等幅2文字分と仮定しているため。本実装では sheet-for-player と同じく、区切りごとに要素を並べるレイアウトにする。

## 決定: 案 C（ChordPro コンテナ + alphaTex パートブロック）

2026-10-03 ユーザーと合意。スクリーンショットを見たうえで「扱いやすさ・わかりやすさは C が一番」との判断。

理由:

1. **歌詞 + コードだけの曲が普通に書ける**。リズム楽器の人や弾き語りの人が最初に作るのはこれで、A と B ではここが不自然になる。
2. **ドラムと将来の Tab譜は alphaTex が一番素直に書ける**。ドラムを `HH`/`SD`/`BD` の名前で書けるので、Drive でテキストを開いても読める。
3. 1曲 = 1テキストファイルで、どのパートも同じファイルの中にある。

形式の例:

```
{title: きらきら星}
{key: C}
{tempo: 100}
{time: 4/4}

{start_of_verse: A}
[C]きらきら[F]ひか[C]る
{end_of_verse}

{start_of_part: Drums}
\section "A"
:8 (HH BD) HH (HH SD) HH (HH BD) (HH BD) (HH SD) HH |
{end_of_part}
```

## 案 C を採用した場合の、M2 で決めること

- **歌詞の重複**: コード譜にもメロディパートにも歌詞が出てくる。正をどちらにするか。
- **セクション構成の共有**: ChordPro の `{start_of_verse: A}` と alphaTex の `\section "A"` を、どう同じ「A」として結び付けるか。
- **`{start_of_part}` は ChordPro 標準のディレクティブではない**: ほかの ChordPro アプリでは、このブロックがそのまま文字として表示される可能性がある。band-sheets 専用の拡張として割り切る。
- **ドラム音色の別名（`HH 42` など）**: ファイルごとに書くか、アプリの既定値として持つか。

## 合意済みの方針（2026-10-03）

- **コードはコード譜とパートでそれぞれ独立して持つ**。基本は同じ内容を書くが、意図的に違う表記も許容する。例: 弾き語り用にコード譜にだけテンションを含めた複雑な解釈を書く、ChordWiki でよく見るリフの単音 `(C) (E) (G)` をコード譜に書く。自動同期や不一致の警告はしない。コード譜のコードは解釈しない文字列として扱う。
- **閲覧時にコード譜と各パートの表示・非表示を切り替えられる**ようにする（M6）。

## 既知の描画上の課題

- alphaTab で、1小節目の練習番号（`\section "A"`）と1拍目のコード名（`ch "C"`）が重なって表示される（`docs/format-spike/shot-a.png`）。M6 で設定か配置を調整する。
- alphaTab の初期設定のままでは、ドラム譜にト音記号が出る（`\clef neutral` で解消）。また、強弱記号「f」が自動で付く（`notation.elements` で `EffectDynamics` を無効にすると解消）。
- 小節番号が表示される点は良い（ユーザー評価）。

## M2 に向けて合意した方針（2026-10-03）

- **歌詞もコード譜とメロディパートでそれぞれ独立して持つ**（コードと同じ考え方）。メロディは音符ごとに音節を分ける必要があるため、M4 のメロディ画面に「コード譜から歌詞を取り込む」補助を用意する。
- **M2 ではパートの中身（alphaTex）を生のテキストのまま持つ**。往復変換で崩れないことだけを保証する。中身の解釈は、各楽器の画面（M4 / M5）が必要な範囲でそれぞれ実装する。
- **セクションはラベル名で対応付ける**。`{start_of_verse: A}` と `\section "A"` は同じセクションとみなす。パート側に一部のセクションがなくてもよい。
