# スパイク 7 T7: 基準線（調整用の合成・既存の合成、そろえた音）

想定読者: G1 で目標を確定するユーザーと、T8〜T12 で「基準 + 差」を使うエージェント。
目的: v1a・v1a＋ベース・v2（V0〜V3、B と音が同じ組の規則は全部切）の今の数字を、調整用の合成だけで固定して残す。目標（§5）は「この基準 + 差」で G1 に決める材料として下の「目標の案」を置く（ここでは確定しない）。

## 測ったもの

- 道具: `spikes/analysis/ts/chords2/eval/baseline.ts`（`run` → `report` → `timing`）、前段 `frontEnd.ts`、集計 `baselineAgg.ts`、設定の固定 `baseline.freeze.test.ts`。個別の結果は `out/chords2-baseline/`（gitignore）。
- 材料（**調整用だけ**。開発用・ホールドアウトの合成・録音は開いていない。`beginLook` も呼んでいない）: chords2 の合成 `c2-t-*` の B 15・V1 15・V2 15・V3 15・pair 216（計 276）、スパイク 6 の B0〜B3（調整用 72。`render/bass/cli.ts` で作り直した）、スパイク 0/2 の既存の合成のうち `heldOut: false` の L0 25・L1 8・L2 2・L3 2・LR 11・LV（段 V の etude）1（計 49。ホールドアウトの etude2/3 は同じ場所に描かれるが、マニフェストの印で除いて読んでいない）。CH（私的な譜面から作る合成）は動かしていない（`recordings/charts` が要り、プライバシーの扱いが別なので。T8 以降の後戻りの見張りに要るなら別に決める）。
- 入力: 全部 `prepareInput`（22,050 Hz に再標本化 → 1 本ごとに RMS −22 dBFS にそろえる。アプリの `inputLevel.ts`）。
- 行: **v1a**（凍結した `ts/dsp` の `analyze`）／**v1a＋ベース (T8 形)**（§5 の基準。ベース入、`weakMinConfidence` 0、分ける・決め直しは切。ハッシュ `3f11c4c58c5a`）／**v1a＋ベース (G2 既定)**（参考の行。分ける・決め直し入。`e5b432a11e3c`）／**v2 V0〜V3**（`bass` と `pairRule` は off。ハッシュ V0 `607593f71c46`・V1 `6b3456aceb5e`・V2 `0832f4e1fe0b`・V3 `61b54aa1fa1b`）。
- 確認: V0 は v1a と **397 本すべて** 同じ区間（開始・終了・ルート・種類・`/X`）。固定のテスト: 上の 2 組のハッシュ（v2 全部切 `607593f71c46` と基準のベース `3f11c4c58c5a`。G2 既定 `e5b432a11e3c` と V1〜V3 も）。
- 再現: T8 形の LR の誤った `/X` は .104（スパイク 6 の LR と同じ）。そろえた音での B1〜B3 の分数は適合率 .80〜.87、再現率 .13〜.24（スパイク 6 T8 の P .819・F .239 と同じ範囲）。
