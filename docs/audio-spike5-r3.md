### 読み方

- **① → ②**: T10 の合わせ込みで S-3 の HH が .342 → .490 に上がった（a は .38 → .70）。BD・SD はほぼ同じ。S-9 は HH を .560 まで上げるが、シンバル類・タムが弱く、全体と格子は ② S-3 より下がる。
- **合成との差**: 既知のキットの D2（S-3 で各楽器 .93〜.98）より大きく低い。録音はライン出力で部屋の響きも雑音も無い「楽観的な見積もり」なのに、HH は未知のキットの合成（T11 のキット D の HH .84）よりも低い。
- **時刻の揺れは主な原因ではない**: 当たった打点のずれは中央値 13〜17 ms、95% 点 42〜44 ms。当たらなかった正解のうち、同じ楽器の推定が 50〜120 ms にあるのは BD 1・HH 1・SD 0 だけ。外れは本当の見落とし・取り違え。
- **直す手数**: キーボードの .67〜.69。録音の願望 ≤ .5 に届かない。コピー版（同じ小節をコピー 1 手と数える）は 2.0〜2.2 で、この 4 本では一から打ち込んでコピーする方が速い。

## 合成と本物の比べ（R2）

本物 = 開発用の録音 4 本（検出した始まりの時刻、他の打点と 30 ms 以上離れた打点）。合成 = 調整用だけ（キット A・D・H、開発用・ホールドアウトの合成は使っていない）。中央値。

| 項目                                       | 本物（aD5）     | 合成 D1 A                            | 合成 D2 A | 合成 D1 D / H  | 合成 D3 A |
| ------------------------------------------ | --------------- | ------------------------------------ | --------- | -------------- | --------- |
| HH のスペクトルの重心（0〜80 ms）          | 5.5 kHz         | 10.7 kHz                             | 10.7 kHz  | 7.4 / 7.5 kHz  | 4.2 kHz   |
| HH の 5 kHz 以上の割合                     | .47             | .80                                  | .79       | .70 / .73      | .23       |
| HH の 5 kHz 以上の大きさ − SD の（全打点） | -9〜-20 dB      | 約 0 dB                              | 約 +1 dB  | 約 +0.5 dB     | -         |
| HH の強さの揺れ（録音の中の標準偏差）      | 7〜16 dB        | 1.2 dB                               | 1.4 dB    | 1.8 dB         | 2.3 dB    |
| SD の 120 Hz 未満の割合                    | .42             | .003                                 | .003      | .001 / .004    | .003      |
| 高いタムの高さ ÷ SD の高さ（`tomPitch`）   | 約 1.0          | .56〜.65（T11b の調整用の 3 キット） |           |                |           |
| 格子からのずれの標準偏差（4 分の位置）     | 21 ms           | 7 ms                                 | 12 ms     | 8 / 8 ms       | 16 ms     |
| ずれの 95% 点                              | 43 ms           | 14 ms                                | 24 ms     | 15 / 15 ms     | 32 ms     |
| テンポのずれ（録音の中の傾き）             | -0.5〜+22 ms/分 | 0                                    | 0         | 0              | 0         |
| 雑音の床（大きい所から）                   | -68 dB          | -103 dB                              | -40 dB    | -101 / -104 dB | -29 dB    |

- HH の強さの揺れの 7 dB は検出された HH の単独の打点、16 dB は正解の時刻の窓（時刻のずれを含む）。どちらでも合成の 1〜2 dB より大きい。合成は MIDI の強さの揺れ σ 8（`variants.ts`）で、音にすると 1〜2 dB にしかならない。
- 正解に印がほぼ無いのに強さの一致が .7 なのも、この強弱の揺れから来る。
- 合成のずれは打点ごとに独立（同時の打点どうしも 20 ms 離れうる）。本物は録音全体が少しずつずれる（傾き）。楽器ごとの決まったずれ（HH が他より約 8 ms 早い）もある（検出の差を含む）。
- タムの数字は 1 本あたり 2〜4 打（合わせて 20 打）で、同時打ちも含むので弱い証拠。

### 合成に足す変化の案

1. **HH の強弱**: 1 打ごとの強さの揺れを音で 6〜15 dB（拍の頭を強く・裏を弱くする型 ＋ ばらつき）。MIDI の σ を上げるだけでは足りない（sf2 の層で 1〜2 dB にしかならない）ので、音の大きさで直接揺らす。
2. **HH を SD より小さく**: HH の 5 kHz 以上の大きさを SD より 10〜20 dB 下げたミックスの型（同時打ちの中の小さい HH）。
3. **暗い HH**: 重心 5〜6 kHz（5 kHz 以上の割合 .4〜.5）になる EQ（6 kHz から上を下げる）をかけた HH・RD の型。
4. **時刻**: 打点ごとの揺れ σ 15〜25 ms、楽器ごとの決まったずれ（±10 ms）、ゆっくりしたテンポのずれ（±20 ms/分）。同時の打点は同じ揺れを共有する。
5. **低い胴の SD とタムの高さ**: SD の 120 Hz 未満を強くし、高いタムを SD とほぼ同じ高さにしたキットの変化（調整用の中で、`tomPitch` の比が 1 近くになる型）。

どれも調整用の素材として足し、調整用だけで値を決める（開発用・ホールドアウトの合成は使わない）。

## G2 の決定の確かめ

- **決定 6（タムの名前は SD の高さとの比 T1 .62・T2 .52・FT .35）**: ユーザーのキット（aD5 TruAcoustic）では成り立たない見込み。`tomPitch` で測った SD の高さ（バックビートの SD でそろって同じ値）と高いタムの高さがほぼ同じ（比 約 1.0）。タムの種の条件「SD の高さの 0.85 倍未満」も満たさず、② S-9 のタムは 20 打のうち当たり 0（T1 → SD 7、T2 → HH 7）。ただし 20 打だけで、同時打ちを含む。ホールドアウトは別のプリセット（Real Groove）なので、そこでも同じかは分からない。
- **決定 1（D1 の HH 95% を S-9 の閉じた HH で見る）**: 合成の D1（合算 .989）は本物に移らない。録音の S-9 の HH は合算 .560（録音ごとに .49〜.61、適合率 .74・再現率 .45）。部屋も雑音も無いライン出力でこの値なので、HH が今のいちばん大きい課題。決定そのもの（合成の判定の仕方）は変えなくてよいが、合成の D1 で 95% を満たすことは本物の HH の精度を保証しない、と結論に書く。

## 未確認

- **スプラッシュ・チャイナ（決定 8 の優先）**: 開発用の 4 本の楽譜にも演奏にも無い（ユーザーの確認: 特殊奏法は出なかった）。録音では確かめられない。T12 の合成の結果（キット A でスプラッシュ .98・チャイナ 1.00、未知のシンバルではチャイナ 0）だけが手がかり。
- カウベル・クロススティック・リムショット・ライドのベル・ペダル HH・フットスプラッシュ: 演奏に無い。分かったのは「無い録音で S-拡張の名前を誤って出す数」（4 本で 7 打）だけ。
- オープン HH（正解 3 打）・FT（2 打）・CR（10 打）: 少なすぎて精度は言えない。CR は推定が 102 打と多すぎることだけが確か。
- d の演奏の後の長い無音: 影響は見えない（最後の小節の後に推定の打点は 0、小節の頭 F 1.000）。
- **1 小節目の前の音（ユーザーに確認したい）**: 4 本とも、ファイルの頭から 1 小節目までの間に大きな打音があり、解析が 8〜11 打（合わせて 37 打）を出す。楽譜の外なので、始まりの F では余計な打点として数えている（格子と直す手数には入らない）。この区間の打点を外すと合算 F は +.01〜.02（② S-9: BD .794・SD .824・HH .570・全体 .590。② S-3: 全体 .646）。叩く前の音（カウントや試し打ち）なら、採点はこの区間を外すのが正しい。T14 の前に決めたい（採点だけの変更で、解析は変わらない）。

## 解析の変更案（今は変えていない）

| 案                       | 中身                                                                                                           | 合成で決められるか                 | 見込み                                |
| ------------------------ | -------------------------------------------------------------------------------------------------------------- | ---------------------------------- | ------------------------------------- |
| A. CR を出す条件を厳しく | S-9 の CR は録音の中の HH の打点より 5 kHz 以上が明らかに大きい（例 +6 dB）ときだけ。HH → CR 73 打を HH に戻す | 合成の変化 1〜3 を足せば決められる | HH・CR の両方が上がる。誤りの最大の塊 |
