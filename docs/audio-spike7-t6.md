## 2. 8 本

開発用 g〜j の中身（キー・テンポ・長さ・左手・形）は `chord-scores/README.md` §6。どれも 4/4・16 小節（1 行 = 4 小節）、40〜60 秒。

- **ホールドアウト k〜n**: ①〜④ を別の調・テンポ・左手の型・進行で。音色は a〜f とも g〜j とも違う 3 つ目のピアノ。中身はここに書かない。
- **開発用との重なり**（度数に直した小節が、対応する開発用の録音にもある数。16 小節中、どこか / 同じ位置）: k 5 / 1、l 10 / 2、m 10 / 2、n 7 / 1。k は独立レビュー（高 1）の後に書き直し、l・n は並べ替えを減らした。テストは「どこか 10 以下・同じ位置 2 以下」。
- **左手の型**: README §2 で「コード 1 つぶん（2 拍か 4 拍）」の単位で決めた（ブロック・白玉・分散の 3 つ。「ルート＋5 度」は 2 つの小節で後ろのコードの下に別の音が鳴るので使わない）。開発用とホールドアウトでは左手の型の割合が違うので、ホールドアウトの判定（開発用との差）を左手の型でそろえて比べるかは G1 で決める（独立レビュー 中 3）。

## 3. 種類の数・`/X` の点（`npx tsx ts/chords2/recScores.ts`）

「出る小節」= その種類が鳴る小節の数、括弧は鳴る長さ（小節）。種類を作る音がベースにしか無い和音（計画 §5「ベースにだけある音」）は種類の数に入れず、別の行に数える。ホールドアウトは合計の数だけ。

| 種類                          | 開発用 g〜j | ホールドアウト k〜n |
| ----------------------------- | ----------- | ------------------- |
| `mM7`                         | 7（3.5）    | 5（2.5）            |
| `m6`                          | 8（4）      | 7（3.5）            |
| `6`                           | 9（5.5）    | 8（5.5）            |
| `sus2`                        | 6（3）      | 6（3）              |
| `7sus4`                       | 7（3.5）    | 7（3.5）            |
| `add9`                        | 5（3.5）    | 5（3.5）            |
| `madd9`                       | 6（3.5）    | 5（3）              |
| `9`                           | 7（3.5）    | 9（4.5）            |
| `m9`                          | 7（3.5）    | 7（4）              |
| `maj9`                        | 7（4）      | 7（4）              |

| 組 `sus2/sus4`: 全 / 食い違う | 7 / 1       | 7 / 1               |

- **基準**（計画 §3.2、2026-11-15 ユーザー）: 段階ごとに 20 以上・種類ごとに 5 以上・`/X` の点 60 以上。全部満たす（いちばん低いのはホールドアウトの V1 の 20）。種類ごとの割合は記録で、判定は段階ごとの合計で読む。
- **`/X` の点**: 1 個の `/X` の和音は 2 拍で 4 点なので、実際の数はおよそ 1/4（開発用 18 個・ホールドアウト 19 個）。採点の表には点と和音の数の両方を出す。g・k に多いが、i・m にも足した。
- **音が同じ組**（計画 §2.3・§5）: 組の当たりは**合成で判定し、録音は記録**。開発用の食い違う例は正解表（T2）と同じ前後。ホールドアウト k には正解表に無い前後を 3 つ入れた（名前はユーザーが確かめる。`README.local.md` の最後）。
- **誤った `/X`**: j・n（分数なし）でも、9 の種類がまだ語彙に無い段階（G2 まで）は 9 の和音が `/X` つきに読まれやすい。採点の表では録音ごとに分け、「正解の種類がその段階の語彙に無い点」を別の列にする。

## 4. 録り足しを提案する所

前もっては録り足さない（2026-11-15、ユーザー）。計画 §3.3 のとおり、G3〜G5 でその段階の決め手の指標の 95 % 区間（区間単位の Wilson）が線をまたぐときだけ、その段階に絞った 2〜4 本を提案する。録音で一番薄いのは V2（4 種類がほぼ i と m の 2 本に入っている）。種類ごとの区間の数は 5〜9 なので、種類ごとの幅は ±.26〜.33 で判定には使わない。
