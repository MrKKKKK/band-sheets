- **S-3 の HH = 0.000 は、未知の音色でも金属の吸収の問題が出た**ことを示す（kit B・開発用 take b の HH .04 と同じ向き）。S-3 は HH を 251 打すべて取り逃し、推定ゼロ。S-9 では HH .708 が出ているので、S-3 の HH の列を金属で埋めてしまう段が原因（解析は変えない）。

- 手数/キーボードは S-9 .499、S-3 .610。S-3 は HH を取り逃した分だけ全部足す手数が増える。S-9 は HH が出るので少なく済む。
