## 作ったもの（`spikes/analysis/ts/chords2/`）

- **B の順の問題（T8 の申し送り）の答え**（`pipeline.ts`）: G2 で B の方法は採らず、スパイク 6 の G2 既定のベースの段階を使うと決まったので、V1 の流れを「chords2（組の規則は切）→ スパイク 6 の印（`marksOnV2`）→ 組の規則（`pairsAfterBass`）」にした。組の規則のベース b は、印が `/X` を付けた区間ではその `/X`、付けていない区間ではその区間の B-1 のベース（T9 の調整と同じ）。出力の `/X` は印に従う（選んだ読みの根音と同じ印は消し、新しい印は足さない）。手作りの例の試験で、印の `/X` が B-1 のベースより優先されることを固定した。

## 気づいたこと

1. **新しい種類はほとんど出せない**: 守りをゆるめても、ベースの入った合成の全帯域のクロマでは足した 1 音（7 度・6 度）が弱く、3 和音に負ける。v1a 自身の 7th も同じ理由で 3 和音に読まれている（`7→maj` が合成で 1058 点）。V1 の問題というより、7 度・6 度を読む力の問題。
2. **出したときも外れが多い**: `6` は `min7` と同じ音なので後置きの規則でしか出ず、その多くが外れ（適合率 .31）。`m6` は比較的当たる（.77）が数が少ない。
3. **録音には効かない**: 開発用の録音では 1 点も新しい種類を出さず、答えは G2 既定と同じ。新しい種類の無い a〜f を壊さない代わりに、g〜j も直さない（候補で直せる所が 100 拍あたり 0.4 増えただけ）。
4. **組の規則**は、組の読みが Viterbi から出る区間が少なすぎて（8/76）、2 つの規則の差も、ベースの点の効きも測れない。
5. 後戻り・誤った `/X`・予算は全部の線を通る（何も変えないので当然に近い）。

## G3 で決めること（ユーザー）

決め手の「新しい種類の適合率（合成）」は .46 で線 .80 に届かず、再現率も .07 です。調整用の合成でも、どの値も .45 を超えませんでした。計画 §5 の止める目安（調整しても適合率 < .60）に当たるので、計画どおり「止める」と「新しい種類は候補だけで出す」の案を出します。

1. **V1 を残すか**
   - 案 A（おすすめ）: **V1 を採らず、V0 ＋ G2 既定のまま**にする。V1 は録音の答えを何も変えず、合成でも新しい種類の当たりより外れが多い。コード（`T10_V1_OVERRIDES`・印の後の組の規則）は切り替えとして残し、持ち越しにする。
   - 案 B: **V1 を「新しい種類は候補だけで出す」で残す**。答えは今と同じ（後戻りなし）で、候補に `mM7` などが出る所が少しある。ただし手で直す数は録音 ALL で 0.1（g〜j で 0.4）、合成で 0.3 しか減らず（線は 1.5）、利点はほとんどありません。
   - 案 C: **V1 を答えとして残す**。決め手の線を外しているので、線を後から下げることになります（G1 の「結果を見てから下げない」に反する）。おすすめしません。
2. **新しい種類を答えで出すか、候補だけか**: 案 A なら決めなくてよい。案 B・C のときだけ。
3. **組の規則**: G1 で先に決めた選び方（差 0 < 5）で **`bassRoot`**。ただし差を測れる数が無い（組として読めた区間 8）ので、V1 を採らない案 A では使わない。
4. **V2 に進むか**
   - 案 A（おすすめ）: **進まない**。V2 の `sus2`・`add9` も「3 和音に 1 音足す」形で、V1 と同じ理由（足した音が 3 和音に負ける）で止まる見込みが高い。語彙の段階はここで止め、T13（Worker・計測ページ）へ進む。持ち越しに「7 度・6 度・9 度を読む力（v1a の 7 度の守り・ベースを抜いたクロマ）」を書く。
   - 案 B: **V2 を測ってから決める**。`sus2` だけは R2 で録音でも少し出ていた（再現率 .42）ので、V2 は V1 と違う結果になる可能性はあります。見る時点 ④ を使います。
   - 案 C: **V2 の前に「7 度を読む力」を直すタスクを足す**（例: ベースを抜いたクロマで 4 音の種類だけを採点する）。計画に無い作業で、v1a の値は変えない約束との関係も決める必要があります。
