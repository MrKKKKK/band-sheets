## S-9 の方法（S-3 の出力は変えない）

`classifyOnsets(det, cfg, table, level)` の `level` が S-9 のとき、S-3 の手順（NMF・合わせ込み）の後に `s9Hits` が楽器を決める。S-3 のときの出力は T10 と同じ（下の adaptSubMin を除く）。

- **BD**: S-3 のまま。**SD**: S-3 のまま。ただしタムがある打点で SD の share < .4 なら消す（タムの音の一部が SD に取られる）。
- **タム**（`toms.ts`）: タムのテンプレート（T1・T2・FT）の share ≥ .4 で、録音の中の基準から -25 dB 以内ならタム。録音の中のタムの打点の数が「SD かタムの打点」の半分を超えたら、その録音にはタムを出さない（別のキットの SD がタムに見えている。タムはフィルだけ）。名前は**録音の中の相対の高さ**: 打点の 10 ms 後から 80 ms の窓のいちばん大きい山（60〜400 Hz、半分の周波数に 3 割以上の山があればそちら = 倍音の取り違えを直す）を、対数で 0.07 オクターブ以上の大きい切れ目で最大 3 つに分け、高い順に T1・T2・FT。2 つ以下のときはテンプレートの票（T1 0・T2 1・FT 2 の平均）で名前を選ぶ。
- **金属**（`cymbals.ts`）: 1 つの打点に金属は 1 つ（HH・HO・RD・CR）。S-3 で HH がある打点か、シンバルの吸収の列（HO・RD・CR・RD.bell・SP・CN）が share ≥ .05 の打点が対象。テンプレートの票（RD.bell → RD、SP・CN → CR）を、キットに依らない 2 つの特徴で直す:
  - **減り方**: 5 kHz 以上のエネルギーが山から 6 フレーム（約 70 ms、次の打点が先なら短くして換算）で何 dB 変わるか。調整用の中央値は 閉じた HH -5.6〜-8.2、HO -1.8〜-2.7、RD -2.8〜-3.5、CR +2（広がりながら鳴る）。
  - **閉じた HH との似方**: 1 kHz 以上の形の、録音の中の閉じた HH（HH だけで速く減る打点の平均）とのコサイン。HO .82〜.94、RD .65〜.93、CR .45〜.76（大まかにしか分けない）。
  - 規則: 減り方 < -4.5 dB → HH。> +0.5 dB で吸収の列が HH の列の半分以上 → CR。それ以外で票の 1 位が金属の票の 7 割未満、かつ減り方 > -3 dB なら、似方 ≥ .83 → HO、そうでなければ RD と CR の票の多い方。票が 7 割以上ならそのまま。
- **合わせ込みの直し（S-3 にも効く）** `adaptSubMin .2`: HH の種の「HH の分」を作るとき、share < .2 の BD・SD の分は引かない。キット H では、キット D の HH の中域をキット A の SD が少し取り、その分を引いた HH のテンプレートでは HH の打点に SD が残っていた（SD の P .41〜.68）。

## T11b: 録音ごとのタムの合わせ込み

設定 `drum-v0` ハッシュ `88d18eb37af0`（T11 は `610eb4f00c26`）。調整用だけ（キット A・D・H、LOPO 16/24/25）。開発用・ホールドアウトは走らせていない。表は T11 と同じ分類だけの合算 F50（`classify_eval.ts --level S-9`）。

### 方法（S-9 だけ。S-3 の出力は変えない）

`classify.ts` 手順 6（`toms.adapt`）: S-3 の手順（合わせ込みまで）の後に、

- **種**（`toms.ts` `tomSeeds`）: キットに依らない特徴で「タムらしい」打点。打点の 10 ms 後から 80 ms の窓のパワーで、S-3 で HH だけではない・70 Hz 未満が 20 Hz〜2.5 kHz の 1 割未満（BD でない）・2.5 kHz 以上が 1 割未満（SD・シンバルでない）・70〜400 Hz が 4 割以上（胴の音。カウベルは .01）・高さ（T11 の `tomPitch`）が録音の中の SD の高さ（S-3 で SD だけの打点の中央値）の 0.85 倍未満・S-3 で BD の share ≥ .5 でない。4 打以上。
- **テンプレート**: 種を高さで最大 3 つに分け（T11 と同じ `groupPitches`）、群ごとに観測の平均を 1 列にして、キットのタムの列（T1・T2・FT）と入れ替え、NMF をやり直す。どれかの群の平均がキットのタムの列と cos ≥ .95 なら入れ替えない（既知のキットを守る。調整用 A・H は ≥ .97、D と LOPO は ≤ .92）。
- **名前**: 入れ替えた列が 3 つなら、打点ごとにいちばん大きいタムの列の名前（打点ごとの高さはオクターブを取り違えることがある）。2 つ以下なら T11 と同じ高さの群で、群の名前は SD の高さとの比（T1 .62・T2 .52・FT .35 の近い方、`ratioVote`）。比は調整用のキット A・A の Power・D のタムの高さから（T1 .56〜.65、T2 .47〜.58、FT .31〜.39）。
- タムの打点では BD も、やり直した NMF の share < .4 なら消す（SD と同じ）。**金属**（HH・HO・RD・CR）は手順 6 の前の NMF から決める（T11 と同じ）。ただしタムの打点では、やり直した NMF でもシンバルの吸収の列が share ≥ .05 のときだけ。

### 大きさ・速さ

- Worker（`drumBench.vite.config.ts` のビルド、gzip -9）: T11 28,938 B → T11b 29,949 B（+1.0 KB）。枠 35 KB（G2 の決定 4）の中。
- Node（devcontainer、D2 の 30 本、2 回）: 音声 1 分あたり、キット A は S-3 約 900 ms・S-9 約 1,020 ms、キット D は S-3 約 1,050 ms・S-9 約 1,300 ms。S-9 の増えは全部の打点のタムの特徴（8192 点の FFT）と、キット D ではタムの列を入れ替えた NMF のやり直し。§5 の速さ（5 分で 15 秒 = 1 分あたり 3,000 ms）の中。
