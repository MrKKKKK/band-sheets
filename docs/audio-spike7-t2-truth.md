# スパイク 7 T2: 音が同じ組の正解表

想定読者: 規則（T9）・合成（T5）・採点を作るエージェントと、結果を見るユーザー。
目的: 音が同じ 2 つのコード名（`C6` と `Am7` など）のどちらを正解とするかを、例の進行ごとに決めた理由を残す（計画の決定 U2。ユーザーが 2026-11-15 に確かめた）。

行のデータ（調・前後・ベース・正解・候補・ノートの §）は `spikes/analysis/ts/chords2/identicalPairs.ts` の `TRUTH_ROWS` / `OTHER_ROWS` だけに置く。ここは ID ごとの理由だけで、テストが ID の一致を確かめる。ノートの § は「和声法ノート v3」（v3 の追記 2026-11 を含む）。

## 1. 音が同じ組

各段階の全部の種類について、12 の根音ごとに鳴る音の集まりを作り、同じ集まりになる組を数えた（`identicalGroups`。V3 の 9 の仲間は 5 度を省いた形も入れた）。テストが「表の組 = 数えた組」を段階ごとに確かめる。

| 段階 | 違う種類どうしで音が同じ組                                                    |
| ---- | ----------------------------------------------------------------------------- |
| 今   | 無し（aug・dim7 は同じ種類の中だけで、規則の外。`ROOT_TIE` のまま）           |
| V1   | `6` と 9 半音上の `m7`（C6 = Am7）、`m6` と 9 半音上の `m7b5`（Am6 = F#m7b5） |
| V2   | 上の 2 つ ＋ `sus2` と 7 半音上の `sus4`（Csus2 = Gsus4）                     |
| V3   | 増えない                                                                      |

V2 の注意: `7sus4` に 5 度を省いた形を認めると、`D7sus4`（5 度なし）= `Gsus4` = `Csus2` の 3 つ組になる（4 度重ねの弾き方）。今の型は 5 度ありだけなので組は 2 つのまま。3 つ組を扱うなら規則を先に広げる（計画 §2.2）。根音を省いた 9 の仲間は計画 §2.2 で扱う。

## 2. 正解の理由

選ばなかった読みは、どの行でもいつも候補に残す（決定、計画 §2.3）。

### 2.1 食い違わない例（ベースの音 = 正解のルート）

| ID  | 理由                                                                                                                                |
| --- | ----------------------------------------------------------------------------------------------------------------------------------- |
| A1  | C6: G7 から I に落ち着く。6 は I の飾り                                                                                             |
| A2  | C6: C – Caug – C6 – C7 の内声のクリシェ（5 度が半音で上がる）                                                                       |
| A3  | Am7: Am – AmM7 – Am7 – Am6 の内声のクリシェ                                                                                         |
| A4  | Am7: Em7 – Am7 – Dm7 と根音が 5 度ずつ下がる                                                                                        |
| A5  | Am7: 短調の iv – i – V                                                                                                              |
| A8  | C6（G 調の IV）: ベースが C で C・E・G がそろう。Am7/C も候補として自然（右手はそのままで、左手の根音だけが A から C へ動く弾き方） |
| B1  | Am6: 内声のクリシェの最後                                                                                                           |
| B2  | Am6: G 調の ii6 → V                                                                                                                 |
| B3  | F#m7b5: 短調の iiø → V                                                                                                              |
| B4  | F#m7b5: Em へ向かう II–V                                                                                                            |
| B7  | Am6: 短調の iv6 → V。ベースが A                                                                                                     |
| B8  | F#m7b5: ベースが G–F#–F–E と半音で下がる ♯ivø                                                                                       |
| C1  | Gsus4: V の掛留が 3 度へ解決                                                                                                        |
| C2  | Csus2: I に落ち着き、2 度が 3 度へ上がる                                                                                            |
| C3  | Csus2: IV と I の行き来。I の 3 度を抜いた形                                                                                        |
| C6  | Asus2: 短調の V → i。2 度が 3 度へ                                                                                                  |
| C7  | Fsus2: C – Fsus2 – F。前の C と根音が続く Csus4 より、ベースの F と解決先が強い                                                     |
