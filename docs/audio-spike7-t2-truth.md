# スパイク 7 T2: 音が同じ組の正解表（下書き・未確認）

想定読者: この表を確かめるユーザー（計画の決定 U2）と、後で規則（T9）を作るエージェント。
目的: 音が同じ 2 つのコード名（`C6` と `Am7` など）のどちらを正解とするかを、例の進行ごとに先に決めておく。ユーザーが確かめるまでは**下書き**で、規則のテストの正解には使わない。

元の計画: `docs/audio-spike7-plan.md` §2.2（語彙の段階）・§2.3（読み分けの規則）。機械が読む同じ表: `spikes/analysis/ts/chords2/identicalPairs.ts`（`TRUTH_DRAFT`、DRAFT の印つき）。ノートへの追加案: `docs/audio-spike7-t2-note-proposal.md`（「案 N1」などはそこを指す）。

## 1. 音が同じ組はいくつあるか（段階ごと）

出し方: 各段階の全部の種類について、12 の根音ごとに音の集まり（12 音のどれが鳴るか）を作り、同じ集まりになる組を全部数えた（`identicalGroups`。V3 の 9 の仲間は 5 度を省いた形も入れた）。テストが「表の組 = 数えた組」を段階ごとに確かめる。

| 段階 | 音が同じ組（種類どうし）                                                      | 新しい組 |
| ---- | ----------------------------------------------------------------------------- | -------- |
| 今   | 無し（aug・dim7 は同じ種類の中だけ。下の「規則の外」）                        | 0        |
| V1   | `6` と 9 半音上の `m7`（C6 = Am7）、`m6` と 9 半音上の `m7b5`（Am6 = F#m7b5） | 2        |
| V2   | 上の 2 つ ＋ `sus2` = 5 度上の `sus4`（Csus2 = Gsus4）                        | 1        |
| V3   | 増えない（9・m9・maj9 は 5 度を省いても他の種類と同じ音にならない）           | 0        |

どの組も 12 の根音すべてで成り立つ（V1: 24 組、V2: 36 組、V3: 36 組）。

規則の外: `aug`（3 つの根音で同じ音）と `dim7`（4 つの根音で同じ音）は今の `ROOT_TIE` のまま（計画 §2.3）。
参考（組ではない）: V3 で根音を省いて弾くと、上の音だけで別のコードになる。C9 の根音なし = Em7b5（= Gm6、V1 の組）、Cm9 の根音なし = Ebmaj7、CM9 の根音なし = Em7。これはベースが C を弾けば 9 の仲間になるので、§2.3 ではなく「ベースがルートを示すときだけ 9 を出す」（計画 §2.2）で扱う。

## 2. 正解表（下書き）

読み方: 「前 → [ ] → 次」の [ ] が音が同じ組の区間。調は C（C 長調）、Am（A 短調）など。正解の案は**ユーザーが確かめる所**、候補はもう一方の読み（結果の `chordCandidates` に残す）。
「規則の目安」: 計画 §2.3 の点を手で計算したもの（調の確信度 1、前後は正解どおり、案 N2・N3 を入れたとき）。「正解の案の点 / 候補の点」。T9 でテストにする前の目安。

## 3. ユーザーの判断が一番要る行

- **A8**（Am → [ ]/C → D7、G 調）: 「Am7/C」か「C6」か。どちらも S の働き。案は Am7/C だが、規則は C6 を出し Am7 を候補にも残さない。C6 で正しいとするなら正解を変える。
- **B7**（Em → [ ]/A → B7）: 「Am6」（iv6）か「F#m7b5/A」（iiø の転回形）か。ポップスでは Am6 と書くことが多いと考え、Am6 を案にした。
- **B8**（G → [ ]/F# → F）: F#m7b5（半音で下がるベース）を案にしたが、規則は Am6 を出す。直すには案 N5（ノートに 1 行足す）が要る。候補に残るので足さない、もありうる。
- **C5**（C → [ ]/D → C/E）: Csus2/D と書くか、G 系（Gsus4/D）と見るか。案は Csus2/D、規則は Gsus4。
- **A6**（ベースが下がるクリシェの Am7/G）: 規則は同点で、「今の語彙を選ぶ」決まりのおかげで当たる。同点の決まりは sus4・m7・m7b5 に寄るので、C 行の sus2 には逆に働く（案 N2・N3 で補う）。

## 4. 確かめてほしいこと

1. 2 章の 22 行の「正解の案」がそれでよいか（特に 3 章の 5 行）。違う行は ID と正しい読みを言ってもらえれば直す。
2. 候補に残す線「差が 0.3 以内」は、0.3 ちょうどを含むか（計画 §2.3 は「以内」、T2 の依頼文は「0.3 未満」）。A7・B5・B6・B8 がちょうど 0.3 なので結果が変わる。案: 含む（「以内」）。
3. 例の数と形: 1 つの組に 6〜8 行、食い違う例 32 %。合成（T5）でこの例をそのまま鳴らす。足りない形があれば足す。
