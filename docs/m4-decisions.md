# M4 メロディの編集画面: 決定事項

スケッチ: Claude Design キャンバス「band-sheets メロディエディタ」（https://claude.ai/artifact/RN2dQNuE3UHomz91xmZrs4）

## ユーザー評価（2026-10-03）

- **方式A（鍵盤＋音価ボタン）と方式B（五線をクリックして置く）の組み合わせが理想**。キーボードでもマウスでも入力・変更できるようにする。
- 方式C（ドレミ文字）は NG ではないが一般的ではない → 採用しない。
- オクターブ移動は Z/X ではなく、修飾キーの組み合わせにしたい。
- 歌詞の割り当ては、キャンバスを見ても操作がイメージできなかった → 詳しい説明と、実際に試せるスケッチを作る。

## キー操作（スケッチで確認済み、2026-10-03 確定）

ブラウザの制約: Tab はフォーカス移動に必要、Ctrl＋文字はブラウザのショートカット（Ctrl+W/T は止められない）、Windows Chrome の Alt+F はメニューを開く → いずれも音の入力には使わない。

| 操作                            | キー                                         |
| ------------------------------- | -------------------------------------------- |
| 音を入力                        | A S D F G H J K（ド〜ド）、W E T Y U（黒鍵） |
| 1音だけ1オクターブ上で入力      | Shift＋音のキー                              |
| 基準オクターブを上げる / 下げる | Ctrl＋↑ / Ctrl＋↓                            |
| 選んだ音符を半音上げる / 下げる | ↑ / ↓（マウスでは上下ドラッグ）              |
| 選んだ音符を1オクターブ上げ下げ | Shift＋↑ / Shift＋↓                          |
| 音価                            | 1 2 4 8 6（全・2分・4分・8分・16分）         |

## 歌詞の割り当て（説明した操作）

1. 取り込み: コード譜のセクションの歌詞を音節に分ける（小さい「ゃゅょ」などは前の字とまとめる）。
2. 自動割り当て: セクション最初の音符から、休符を飛ばして 1 音 1 音節で並べる。数が合わないときは件数と、ずれ始めの位置を表示する。
3. 直す（後ろはまとめてずれる）: のばす（メリスマ、後ろが右へ）／つめる（1 音に 2 音節、後ろが左へ）／分ける（つめるを戻す）／歌詞なし（後ろが右へ）。

## デザイン確定（2026-10-03）

ユーザーがキャンバス（Combined = A＋B、LyricsAssign の操作デモ）を一通り確認し、**このデザインで進める**と決定。方式C（ドレミ文字）は不採用。

## 実装計画での確認結果（2026-10-03）

- 2 番など歌詞だけ違うセクションは、コード譜で **別ラベル（例: A2）** にする。M4 は「1 ラベルにメロディ 1 つ」。
- 音符を足したり消したりしたとき、歌詞は **後ろにずれる**（「後ろはまとめてずれる」を追加・削除にも適用）。
- 音節: 小書きの「ゃゅょ」等と「っ」は前の字とまとめる（がっ／こ／う）、「ー」は 1 音節（ラ／ー／メ／ン）。
- 入力用の五線は簡略版（連桁なし・旗、臨時記号は毎回表示）。正式な見た目は下の確認用表示（alphaTab）。小節をまたぐ音は自動でタイ、弱起は M4 では扱わない（休符で埋める）。

## 実際に触ってのフィードバック（2026-10-04）

- 全体として「非常に使いやすい」。
- **コード譜の行の区切り印（M14）は不要** → 機能ごと削除する。
- **1 つの音節を複数の音符で歌う（のばす / メリスマ）ときはスラーでつなぎたい** → のばした範囲に自動でスラーを付ける（入力用の五線と alphaTab の両方）。追加の操作は増やさない。
- **マウス操作後にキーボード入力へ戻る条件がわかりにくい** → 今の動作は変えず、五線の上に「入力中」／「N 音目を選択中（Esc または空いた所をクリックで入力に戻る）」を常に表示し、「入力に戻る」ボタンを置く。
