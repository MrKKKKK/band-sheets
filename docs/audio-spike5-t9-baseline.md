## G1 への提案

事実: 差はほぼ全部「キット」が原因。キット A なら tuning も dev も D0〜D2 の目標を満たす。キット B（tuning に無い）で HH と BD/SD が崩れる。D3 は A でも HH .68〜.70、格子 .80。

目標の案:

1. D0〜D2 の F・格子・シャッフルは目標を維持。ただし「キット A（既知のキット）で」と明記する。
2. 未知のキット用に別の行を新設する（今は記録のみ。値は T10 の結果を見て決める）。「調整用と開発用の差 .1」はキット込みで判定する（現状は未達）。
3. 直す手数/キーボード D2 ≤ .2 は縁なので維持するか .25 に緩めるかを選ぶ。
4. D3 は記録のまま。
5. Worker の大きさ 25 KB は 0.5 KB 超過。目標を 26 KB にするか削るか。

直す順番の選択肢（効果は推定。T10 は合成で判断できる変更 1 回まで）:

- A. 録音ごとにテンプレートを測り直す（T6 の refit の切り替えを有効にする案。設定の値の変更）。期待: キット B の HH・BD の崩れを狙う。効果が最も大きい見込みだが、B で本当に戻るかは試すまで未確認。
- B. 調整用にキット B（と C）を加えて調整する。偏りが減るが、開発用の独立性が下がる（B を dev から外すかの判断が要る）。
- C. D3（ノイズ・響き）の見逃しと余計な SD を減らす（閾値・帯域の調整）。キット A の D3 を上げる効果。D0〜D2 は変わらない見込み。
- D. 何も直さず、キット A 前提で S-9 へ進む。
