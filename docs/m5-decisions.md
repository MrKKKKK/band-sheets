# M5 ドラムの編集画面: 決定事項

スケッチ: Claude Design キャンバス「band-sheets ドラムエディタ」（https://claude.ai/artifact/FCAttSBCs1iVjLw5JGqgWf）

## ユーザー判断（2026-10-04）

- **方式C（五線＝ドラム譜に直接入力）を基本にする**。メロディ（M4）と同じ操作感。方式A（ステップシーケンサー）・B（パターンを並べる）は採用しない。
- **シャッフルは音価で表さず、一般的な楽譜の「Shuffle」表記で表す**（alphaTab の triplet feel 相当。実装前に alphaTex での書き方と描画を確認する）。
- **連符は任意の N 連符（3・5・6・7…）に対応する**。フュージョンなど複雑なリズムを想定。ドラムとメロディの共通の仕組みとして作る（M4 で読み取り専用にしていた連符を編集できるようにする）。
- 実装の前に、方式C を試せる形（楽器のキー割り当て、同時打ち、連符、シャッフル表示）にスケッチを作り直して確認する。

## スケッチ確認（2026-10-04）

- 作り直したスケッチ（案C・操作できる版）の内容で**承認**。次の操作を実装の基準にする。
  - キー割り当て: F=スネア、J=バスドラム、H=ハイハット（クローズ）、G=ハイハット（オープン）、K=ハイタム、L=ミッドタム、;=フロアタム、U=クラッシュ、I=ライド
  - Shift＋キー: 直前の拍にその楽器を足す／もう一度で外す（同時打ち）
  - 「連符」ボタン: 3・5・6・7・その他（任意の N）
  - シャッフル: セクションごとに 8分／16分／なし を選び、譜面に Shuffle 表記を出す（音価は変えない）
- alphaTex の書き方は docs/m5-alphatab-findings.md の調査結果に従う。
- **フラムは M5 では見送る**。奏法記号はゴーストノートとアクセントまで。
