# M6 タブレット向けの閲覧画面: 決定事項

スケッチ: Claude Design キャンバス「band-sheets 閲覧画面（M6）」（https://claude.ai/artifact/JUUh33ZzeJSvy18apK5jh8）

## ユーザー判断（2026-10-05）

- **使う場面**: バンド練習・ライブ（譜面台に置き、演奏中で手がふさがっている）と、個人練習・確認の両方。
- **ページ送り**: ページめくり（左右タップ。フットペダルも想定）、縦スクロール、自動スクロール（テンポに合わせる）の 3 つすべてを使えるようにする。
- **表示の組み合わせ**: 「自分のパート＋コード譜」と「全パートを小節をそろえて並べる（スコア）」の両方を用意し、切り替えて使う。
- 持ち越しの課題: M5 レビュー R7（`\tf` は全パート共通の小節単位の設定なので、全パートを並べて描くとシャッフル表記がずれる）と、format-decision.md の「1 小節目の練習番号とコード名が重なる」を M6 で扱う。
- 実装の前に Claude Design でスケッチを作り、合意してから進める。

## スケッチ確認（2026-10-05）

- 操作の部品は **案A（上のバー）**。演奏モードで隠せる。
- 文字の大きさの設定は **譜面全体（五線譜も含む）** を拡大する。
- 自動スクロールのカウントインは **1 小節（拍子どおり）**、入り切りできる。
- スコア表示の案を採用: 練習番号は五線の左の専用の列に置いてコード名と重ねない。Shuffle 表記はドラムの段のセクションの頭だけに出す（メロディには出さない）。
- 設定（表示の組み合わせ・パート・ページの進め方・文字の大きさ）は曲ごとに覚える。
- 確認の方法: M6 の間は PC のブラウザ（タブレットの画面サイズ）とタッチ操作の自動テスト（Playwright のタブレット端末の設定）で確かめる。実際のタブレットでの確認は M7（Google Drive）のあと。
