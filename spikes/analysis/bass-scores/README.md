# ピアノ録音の手順（スパイク 6・ベース／分数コード）

想定読者: ピアノ（電子ピアノ）で 6 本を録るユーザー。
目的: こちらが書いた楽譜 6 本（a〜f）を、アプリで見ながら弾いて録音し、`bas-inbox` に入れるまでの手順。コード譜が正解になるので、**書いてあるベース音のとおりに弾く**のが一番大事。曲は全部こちらで作った練習用で、実在の曲ではありません。

## 1. 楽譜を曲として作る（6 本とも同じ）

1. このフォルダの `a.song.txt` … `f.song.txt` を開いて全部コピー（場所: `spikes/analysis/bass-scores/`）。
2. アプリで 曲の一覧 → **新しい曲** → **テキスト入力** → 貼る → 保存。曲名は `録音用 a（転回形・ブロック）` のように自動で付きます。
3. 6 本ぶん繰り返す。
4. 録るときはアプリで曲を開き、**ビューア**にして見ながら弾く。ビューアには 1 行 = 4 小節のブロック（A〜D）が出ます（`-` は 8 分音符 1 つぶん。1 小節 = `-` 8 個で、コードが 2 つの小節は前半・後半に 1 つずつ）。**左手で弾くベース音** は、コードの `/` の後ろの音（`/` が無いコードは根音）です。テンポは曲の `tempo`（`.txt` の `bpm:` と同じ）。

## 2. 弾き方（左手と右手）

共通: **右手 = 3 和音だけ**（メロディは入れない。C4〜B4 のあたり、転回形はどれでもよい。4 つの音のコード `Em7` `A7` は 4 音）。**左手 = ベース音**（C2〜B2 くらいの出しやすい高さ。右手より必ず低く）。ダンパーペダルは**踏まない**（前の和音が残ると正解が不公平になる）。

| 左手の型         | 弾き方                                                                                                                                                                                                                        |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ブロック（a）    | 1 拍目と 3 拍目に両手を同時に弾く。左手 = ベース音 1 つ（オクターブでもよい）。1 小節に和音が 2 つの小節は、1 拍目に前の和音、3 拍目に後ろの和音                                                                              |
| 白玉（b・e）     | 1 小節に 1 回、両手とも全音符で伸ばす。和音が 2 つの小節は 2 分音符ずつ                                                                                                                                                       |
| 分散（c・f）     | 左手は 4 分音符 4 つ「ベース音 → 5 度 → 高いベース音（1 オクターブ上）→ 5 度」。5 度 = コード名の頭の音（根音）から数えた 5 度。例: `C/E` は 低い E → G → 高い E → G。`G/B` は B → D → B → D。右手は 1 拍目と 3 拍目に 3 和音 |
| ルート＋5度（d） | 左手は 1 拍目にルート、3 拍目にその 5 度上（`D` なら D と A）。右手は 1 拍目と 3 拍目に 3 和音。**d には `/` のコードが無い**ので、右手の 3 和音は弾きやすい転回形でかまいません                                              |

## 3. 録り方

- **クリック**: ヘッドホンだけに聞こえるようにする（DAW のクリック。録音に**入れない**）。曲の `tempo` に合わせる。
- **カウント**: 録音の頭に **1 小節のクリックだけ**を置き、2 小節目から楽譜の 1 小節目を弾く。
- **録音**: 電子ピアノのライン出力を WAV（44.1 または 48 kHz、モノでもステレオでも可）で録る。リバーブ・コーラスなどの効果は切る（ピアノの音色は、a〜d で 1 つに決めて 4 本とも同じにする。e・f は下の「順番」のとおり別の音色）。
- **長さ**: 最後の小節の和音を弾いたら、余韻が消えるまで止めずに録る。
- 間違えても止めず最後まで弾く。楽譜と違った小節は、あとで `.txt` の「楽譜と違って弾いた小節:」に番号を書く（採点から外れる）。やり直しは何度でも可、**良かった 1 本**だけを残す。
- 順番: a → b → c → d → e → f。**e・f は a〜d と別のピアノの音色で録ってください**（例: a〜d がグランドピアノなら e・f はアップライト）。知らない音にも効くかを確かめるためです（ユーザーの決定、2026-11-01）。エレピやオルガンのように大きく違う音は避けます。どの音色にしたかは、各 `.txt` の `機材:` に書いてください。

## 4. 書き出しと `開始:`（ここを間違えやすい）

`開始:` は **楽譜 1 小節目の頭（最初の和音を弾いた瞬間）が、書き出した WAV の何秒目か** です。スパイク 5 では、書き出しをずらしたのに `.txt` の値が元のままで、ずれがしばらく気付かれませんでした。書き出し方を決めたら、必ず次のどちらかに合わせて書き直してください。

| 書き出し方                                                  | `開始:`                                     |
| ----------------------------------------------------------- | ------------------------------------------- |
| クリックのカウント 1 小節（4 拍）を含めて、頭から書き出した | `.txt` に入っている値のまま（4 拍ぶんの秒） |
| カウントを切って、1 小節目の頭ちょうどから書き出した        | `0秒`                                       |
| 録音の頭に余分な空きがある（上のどちらでもない）            | 下の「測り方」で測った秒                    |

測り方: 書き出した WAV を DAW か Audacity で開き、**最初の和音（1 小節目の 1 拍目）の音が出る瞬間**の秒を読む。0.1 秒くらいの誤差は取り込みが直します。

例（a、bpm 84、カウント 1 小節 = 4 × 60 ÷ 84 = 2.857 秒）:

- カウントから書き出した → 最初の和音は約 2.9 秒のところ → `開始: 2.857秒`（そのまま）。
- 1 小節目の頭から書き出した → 最初の和音は 0 秒のところ → `開始: 0秒` に直す。直さないと 1 小節（約 2.9 秒）ずれたまま採点されます。
- 録音ボタンを押してから 1 秒待って、そのあとカウントが入っていた → 最初の和音は約 3.9 秒 → `開始: 3.9秒`。

取り込みは、`開始:`・bpm・小節数と録音ファイルの**長さ**が合うかだけを確かめます（音の頭は見ません。1 小節早い `開始:` は余韻が短いと通ってしまうことがあります）。合わなければエラーが出るので、その場合は `開始:` を測り直してください。音の頭のずれは、採点の前の時刻合わせ（`fit_grid`）の残差で別に見ます。

## 7. ホールドアウト（e・f）の決め方

ホールドアウトは **e と f**（開発用は a〜d）。解析の前に決めて取り込みが記録し、後から変えません。

- **e**: b と同じ「クリシェ・ペダル・白玉」だが、キー（G・Em）、順番（短調のクリシェ → ペダル → 長調のクリシェ）が違う別の楽譜。クリシェとペダルが録音の中でどれだけ当たるかの最後の確認。
- **f**: c と同じ「分散・下がる階段・転回形」だが、キー（F）、順番、5 度のベース（F/C）の位置が違う別の楽譜。5 度の取り違えの最後の確認。
- **条件**: e・f の形は、すべて a〜d のどれかにも入っている（下の表）。ホールドアウトにだけある形は無い。分数コード無し（d）は開発用だけで、誤った `/X` の数は d と、他の録音の「`/` が無い小節」で見ます。

| 形                                 | a      | b      | c      | d      | e                  | f                  |
| ---------------------------------- | ------ | ------ | ------ | ------ | ------------------ | ------------------ |
| 転回形（第 1 転回: 3 度がベース）  | ○      |        | ○      |        |                    | ○                  |
| 転回形（第 2 転回: 5 度がベース）  | ○      |        |        |        |                    | ○                  |
| 下がるベースのクリシェ             |        | ○      |        |        | ○                  |                    |
| ペダル（同じベースで和音が動く）   |        | ○      |        |        | ○                  |                    |
| 経過のベース（C–C/D–Em 型）        | ○      |        |        |        |                    |                    |
| 下がる階段のベース（転回形つなぎ） |        |        | ○      |        |                    | ○                  |
| 開発用 / ホールドアウト            | 開発用 | 開発用 | 開発用 | 開発用 | **ホールドアウト** | **ホールドアウト** |

（○ = その録音に入っている形。`INV3` は 3 度がベースの転回形、`INV5` は 5 度がベース。クリシェとペダルは b と e、下がる階段のベースは c と f、経過のベースは a だけにあり、ホールドアウトに無い形は経過のベースだけ。）
