# 電子ピアノ録音の手順（スパイク 7・コードの種類と転回形）

想定読者: 電子ピアノで 8 本（g〜n）を録るユーザー。
目的: こちらが書いた楽譜 8 本を、アプリで見ながら弾いて録音し、`chd-inbox` に入れるまでの手順。コード譜がそのまま正解になるので、**書いてあるコードとベース音のとおりに弾く**のが一番大事です。曲は全部こちらで作った練習用で、実在の曲ではありません。

8 本は **開発用 g〜j**（このフォルダ）と **ホールドアウト k〜n**（git に入らない別のフォルダ。§7）に分かれます。弾き方・録り方はどちらも同じです。

## 1. 楽譜を曲として作る

1. `g.song.txt` … `j.song.txt`（このフォルダ `spikes/analysis/chord-scores/`）と、`k.song.txt` … `n.song.txt`（§7 のフォルダ）を開いて全部コピー。
2. アプリで 曲の一覧 → **新しい曲** → **テキスト入力** → 貼る → 保存。曲名は `録音用 g（転回形・ベースのクリシェ）` のように自動で付きます。
3. 8 本ぶん繰り返す。
4. 録るときはアプリで曲を開き、**ビューア**にして見ながら弾く。1 行 = 4 小節のブロック（A〜D）です（`-` は 8 分音符 1 つぶん。1 小節 = `-` 8 個。コードが 2 つの小節は前半・後半に 1 つずつ）。テンポは曲の `tempo`（`.txt` の `bpm:` と同じ）。

## 2. 弾き方（左手と右手）

共通:

- **左手 = ベース音 1 つ**（オクターブで重ねてもよい）。`/` の後ろの音、`/` が無いコードは根音（コード名の頭の音）。C2〜B2 くらいの出しやすい高さで、右手より必ず低く。
- **右手 = コードの音**（メロディは入れない）。C4〜B4 のあたりで、弾きやすい転回形でかまいません。新しい種類のコード（下の §6 に書いたもの）は、書いてある右手の音で弾いてください。
- `/` のコードは、**右手は `/` の前のコードの形のまま、左手だけ動かす**。例: `C → C/D → C/E` は、右手は C・E・G のまま、左手が C → D → E。
- ダンパーペダルは**踏まない**（前の和音が残ると正解が不公平になる）。

| 左手の型                | g〜j     | 弾き方                                                                                                                                                       |
| ----------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ブロック                | g・j     | 1 拍目と 3 拍目に両手を同時に弾く。コードが 2 つの小節は、1 拍目に前のコード、3 拍目に後ろのコード                                                            |
| 白玉                    | h        | 両手とも伸ばす。コードが 1 つの小節は全音符、2 つの小節は 2 分音符ずつ                                                                                        |
| 分散                    | i        | 左手は 4 分音符 4 つ「ベース音 → 5 度 → 高いベース音（1 オクターブ上）→ 5 度」。5 度 = 根音から数えた 5 度（`C/E` なら E → G → E → G）。右手は 1 拍目と 3 拍目 |
| ルート＋5 度            | —        | 左手は 1 拍目にベース音、3 拍目に根音から数えた 5 度（`A` なら A と E、`A/C#` なら C# と E）。右手は 1 拍目と 3 拍目                                          |

k〜n がどの型かは、§7 の `README.local.md` に書いてあります。

## 3. 録り方（スパイク 6 と同じ）

- **クリック**: ヘッドホンだけに聞こえるようにする（録音に**入れない**）。曲の `tempo` に合わせる。
- **カウント**: 録音の頭に **1 小節のクリックだけ**を置き、2 小節目から楽譜の 1 小節目を弾く。
- **録音**: 電子ピアノのライン出力を WAV（44.1 または 48 kHz、モノでもステレオでも可）で録る。リバーブ・コーラスなどの効果は切る。
- **音色**: **g〜j は 1 つのピアノの音色**に決めて 4 本とも同じにする（スパイク 6 の a〜d と同じ音色でよい）。**k〜n は別の音色**（§7）。どの音色にしたかは各 `.txt` の `機材:` に書く。
- **長さ**: 最後の小節を弾いたら、余韻が消えるまで止めずに録る。
- 間違えても止めず最後まで弾く。楽譜と違った小節は、あとで `.txt` の「楽譜と違って弾いた小節:」に番号を書く（採点から外れる）。やり直しは何度でも可、**良かった 1 本**だけを残す。

## 4. 書き出しと `開始:`

`開始:` は **楽譜 1 小節目の頭（最初の和音を弾いた瞬間）が、書き出した WAV の何秒目か** です。

| 書き出し方                                                  | `開始:`                                     |
| ----------------------------------------------------------- | ------------------------------------------- |
| クリックのカウント 1 小節（4 拍）を含めて、頭から書き出した | `.txt` に入っている値のまま（4 拍ぶんの秒） |
| カウントを切って、1 小節目の頭ちょうどから書き出した        | `0秒`                                       |
| 録音の頭に余分な空きがある（上のどちらでもない）            | 最初の和音の音が出る瞬間の秒を測って書く    |

いつもどおりカウントを含めて書き出したなら、`開始:` は**直さなくてよい**です。取り込みは `開始:`・bpm・小節数と録音ファイルの**長さ**が合うかだけを確かめ、合わなければエラーを出します（音の頭は見ません）。

## 6. 開発用 g〜j の中身

どれも 4/4・16 小節。新しい種類のコードの右手は下のとおり（左に書いた音から上へ順に。`（左手 X）` はベース音）。

| 録音 | キー        | テンポ | 長さ     | 左手     | 入っている形                                                                                                         |
| ---- | ----------- | ------ | -------- | -------- | -------------------------------------------------------------------------------------------------------------------- |
| g    | C           | 84     | 約 46 秒 | ブロック | ベースが歩く転回形（C → C/D → C/E）、下がるベースのクリシェ（Am → AmM7/G# → Am7/G → Am6/F#）、`C6/E`・`Gsus4/D`      |
| h    | Am（→ C）   | 72     | 約 53 秒 | 白玉     | 内声のクリシェ（ベースはそのまま、右手の 1 音だけ動く）: Am・Dm の 4 つ組、C → Caug → C6 → C7、`Fm6/C`                |
| i    | G           | 92     | 約 42 秒 | 分散     | ポップスの sus2・add9・madd9・7sus4（sus は解決する）、`Cmaj9`・`Em9`・`A9` の 1 行                                    |
| j    | F           | 80     | 約 48 秒 | ブロック | 9 の和音（maj9・m9・9）と `C7sus4`、内声のクリシェ（Gm・Dm）。**`/` のコードは無し**（誤って `/X` が出るかを見る）   |

**g**（ベースが歩く・下がる）

- `C/D` = 右手 C・E・G（左手 D）、`Am7/G` = 右手 A・C・E（左手 G）、`Gsus4/D` = 右手 G・C・D（左手 D）
- `C6/E` = 右手 C・E・G・A（左手 E）、`C6` = 右手 C・E・G・A（左手 C）
- `AmM7/G#` = 右手 A・C・E（左手 G#）、`Am6/F#` = 右手 A・C・E（左手 F#）。右手は Am の形のまま、左手だけ A → G# → G → F#
- `Fsus2` = 右手 F・G・C（左手 F）、`Fm6` = 右手 F・Ab・C・D（左手 F）、`G7sus4` = 右手 C・D・F（左手 G）

**h**（内声のクリシェ。左手は動かず、右手の 1 音だけが半音ずつ動く）

- `Am` = 右手 C・E・A（左手 A）→ `AmM7` = 右手 C・E・G#（左手 A）→ `Am7` = 右手 C・E・G（左手 A）→ `Am6` = 右手 C・E・F#（左手 A）
- `Dm` = 右手 F・A・D（左手 D）→ `DmM7` = 右手 F・A・C#（左手 D）→ `Dm7` = 右手 F・A・C（左手 D）→ `Dm6` = 右手 F・A・B（左手 D）
- `C` = 右手 E・G・C（左手 C）→ `Caug` = 右手 E・G#・C（左手 C）→ `C6` = 右手 E・G・A・C（左手 C）→ `C7` = 右手 E・G・Bb・C（左手 C）
- `Fm6` = 右手 F・Ab・C・D（左手 F）、`Fm6/C` = 右手 F・Ab・D（左手 C）、`Bm7b5` = 右手 D・F・A（左手 B）、`E7` = 右手 D・G#・B（左手 E）

**i**（ポップス）

- `Gadd9` = 右手 A・B・D（左手 G）、`Cadd9` = 右手 D・E・G（左手 C）、`G6` = 右手 B・D・E（左手 G）
- `Dsus2` = 右手 D・E・A（左手 D）、`Csus2` = 右手 C・D・G（左手 C）、`Gsus2` = 右手 G・A・D（左手 G）、`Esus2` = 右手 E・F#・B（左手 E）
- `Emadd9` = 右手 F#・G・B（左手 E）、`Amadd9` = 右手 B・C・E（左手 A）
- `D7sus4` = 右手 G・A・C（左手 D）
- `Cmaj9` = 右手 E・G・B・D（左手 C）、`Em9` = 右手 G・B・D・F#（左手 E）、`A9` = 右手 C#・E・G・B（左手 A）

**j**（9 の和音。**A・B の行は右手 4 音、C・D の行は右手 3 音（5 度を抜く）**で弾く）

- A・B の行（4 音）: `Fmaj9` = 右手 A・C・E・G（左手 F）、`Dm9` = 右手 F・A・C・E（左手 D）、`Gm9` = 右手 Bb・D・F・A（左手 G）、`C9` = 右手 E・G・Bb・D（左手 C）、`Bbmaj9` = 右手 D・F・A・C（左手 Bb）、`Am9` = 右手 C・E・G・B（左手 A）、`G9` = 右手 B・D・F・A（左手 G）
- C・D の行（3 音）: `C9` = 右手 E・Bb・D（左手 C）、`G9` = 右手 B・F・A（左手 G）、`D9` = 右手 F#・C・E（左手 D）、`Gm9` = 右手 Bb・F・A（左手 G）、`Bbmaj9` = 右手 D・A・C（左手 Bb）
- そのほか: `C7sus4` = 右手 F・G・Bb（左手 C）、`Dmadd9` = 右手 E・F・A（左手 D）、`GmM7` = 右手 Bb・D・F#（左手 G）、`DmM7` = 右手 F・A・C#（左手 D）、`Bbm6` = 右手 Db・F・G（左手 Bb）、`F6` = 右手 A・C・D（左手 F）

## 7. ホールドアウト k〜n

ホールドアウトは **k〜n**（開発用は g〜j）。解析の調整には使わず、最後に 1 回だけ「知らない録音でも効くか」を確かめるための録音です。取り込みは解析の前にこの区分を記録し、後から変えません。

- **楽譜の場所**（git に入らないフォルダ。中身は解析の作業でも開きません）:
  - WSL: `/home/mrk5/projects/band-sheets/.worktrees/spike7/spikes/analysis/recordings/chd-heldout-scores/`
  - Windows: `\\wsl.localhost\Ubuntu\home\mrk5\projects\band-sheets\.worktrees\spike7\spikes\analysis\recordings\chd-heldout-scores`
  - `k.song.txt` … `n.song.txt`（アプリに貼る楽譜）と、`README.local.md`（k〜n の左手の型と、新しい種類のコードの右手。§6 と同じ書き方）があります。
- **中身**: k〜n は g〜j と同じ 4 つの形（① 転回形とベースのクリシェ、② 内声のクリシェ、③ sus2・add9 のポップス、④ 9 の和音・分数なし）を、**別の調・テンポ・左手の型・順番**で書いた別の楽譜です。
- **音色**: **k〜n は、これまでの録音（スパイク 6 の a〜f）とも g〜j とも違う、3 つ目のピアノの音色**で録ってください（例: グランドピアノの別の種類、アップライト）。エレピやオルガンのように大きく違う音は避けます。4 本とも同じ音色にして、`機材:` に書きます。
