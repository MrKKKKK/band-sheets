# ドラム録音の手順（スパイク 5・電子ドラム aD5）

想定読者: 電子ドラム（ATV aDrums aD5）で 6 本を録るユーザー。
目的: こちらが書いた楽譜 6 本（a〜f）を、アプリで見ながら叩いて録音し、`drm-inbox` に入れるまでの手順。楽譜が正解になるので、**楽譜どおりに叩く**のが一番大事。

## 1. 楽譜を曲として作る（PC、6 本とも同じ）

1. 渡された `a.song.txt` … `f.song.txt`（場所は報告に書いてあります。`recordings/drum-scores/`）を開いて全部コピー。
2. アプリで 曲の一覧 → **新しい曲** → **テキスト入力** → 貼る → 保存。曲名は `録音用 a（8 ビート）` のように自動で付きます。
3. 6 本ぶん繰り返す。ドラム画面とビューアの両方で表示されることを、1 本だけ開いて確かめてください。
4. 録るときは Chromebook（またはタブレット・PC）で曲を開き、**ビューア**にして見ながら叩く。譜面は 4 〜 8 小節ごとのブロックに分けてあり、各ブロックの上に「1〜8 小節」のように小節番号が出ます。テンポは曲の `tempo` です（`.txt` の `bpm:` と同じ）。

## 2. 録り方

- **クリック**: ヘッドホンだけに聞こえるようにする（DAW のクリックか aD5 のメトロノーム。ライン出力の録音に**入れない**）。曲の `tempo` に合わせる。
- **カウント**: 録音の頭に **1 小節のクリックだけ**を置き、2 小節目から楽譜の 1 小節目を叩く。小節の数え方は楽譜の小節番号（1 〜）どおり。
- **録音**: aD5 のライン出力を WAV（44.1 または 48 kHz、モノでもステレオでも可）で録る。エフェクト（リバーブ・コンプ）はできるだけ切る。
- **長さ**: 楽譜の最後（最後の小節の全音符のクラッシュ + バスドラ）を叩いたら、余韻が消えるまで止めずに録る。
- 間違えても止めず、最後まで叩く。間違えた・楽譜と違って叩いた小節は、あとで `.txt` の「楽譜と違って叩いた小節:」に番号を書く（採点から外れます）。やり直しは何度でも可、**良かった 1 本**だけを残す。

## 3. キット（プリセット）

- **a〜d（開発用）**: aD5 のキットを 1 つ選ぶ（例: 標準的なアコースティック系）。
- **e・f（ホールドアウト）**: a〜d と**はっきり違う別のキット**（音色・チューニングが違うもの）に切り替えて録る。
- 各 `.txt` の `キット:` に、使ったキットの名前か番号を書く（a〜d は同じ、e・f は別のもの）。

## 4. 特殊奏法（d だけ）

アプリの譜面には書けない叩き方を d で録ります。`d.txt` に `特殊奏法:` の行があり、その小節だけ指定どおりに叩く（譜面上は普通の SD / RD のまま）。
- 9〜10 小節: ライドを**ベル**で叩く（四分音符）
- 11〜12 小節: スネアを**クロススティック**で
- 13〜14 小節: スネアを**リムショット**で
aD5 で出ない場合は、その行を消して「出なかった」とだけ書いてください。

## 5. ファイルを入れる

録音を `a.wav` … `f.wav` の名前にして、`.txt`（`a.txt` … `f.txt`、すでにここに入っています）と並べる:

- WSL: `/home/mrk5/projects/band-sheets/spikes/analysis/recordings/drm-inbox/`
- Windows: `\\wsl.localhost\Ubuntu\home\mrk5\projects\band-sheets\spikes\analysis\recordings\drm-inbox`

`.txt` で書き込むのは `キット:`、`開始:`（あとで説明）、「楽譜と違って叩いた小節:」だけ。`bpm:`・`拍子:`・`叩き方:`・`ホールドアウト:` は変えない（e・f がホールドアウトで、その印は取り込みが解析の前に記録します）。

- `開始:` は楽譜 1 小節目の頭の秒。カウント 1 小節を含めて頭から書き出したなら、入っている値（= 4 拍ぶんの秒）のまま。カウントを切って 1 小節目の頭から書き出したなら `0秒` に直す。
- 録音は**このコンピューターの中だけ**に置かれます（`recordings/` は git に入らず、Drive・Artifact にも出しません）。

## 6. 録る順番

a → b → c → d（同じキット）→ キットを切り替え → e → f。e・f の楽譜は a〜d と同じ種類の叩き方で、別の楽譜です。
